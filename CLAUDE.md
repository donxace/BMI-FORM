
# Project Development Instructions

## Before coding

- Inspect the existing implementation.
- Understand the architecture before changing files.
- Identify dependencies and affected components.

## Implementation

- Preserve existing functionality.
- Follow existing coding conventions.
- Avoid unnecessary libraries and abstractions.
- Make small, focused changes.
- Do not invent APIs, database fields, or requirements.

## Git safety

- Do not work directly on main.
- Inspect git status before editing.
- Never overwrite unrelated changes.
- Keep changes scoped to the assigned task.

## Verification

- Run relevant tests and builds.
- Report the files changed.
- Report actual test results.
- Identify unresolved issues.
